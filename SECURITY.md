# Security Policy

## Supported versions

Only the latest commit on `main` is supported. Fixes reach https://dropx.click by deploying `main`.

## Report a vulnerability

Report it privately through [GitHub private vulnerability reporting](https://github.com/ingvarch/dropx/security/advisories/new). Only the maintainer can see the report. Do not open a public issue, pull request or discussion about it.

Include:

- what an attacker can do and what they need for it;
- the steps or requests that show the problem (a `curl` command is best);
- the route, header or component involved.

The maintainer replies in the advisory, agrees on a fix and a disclosure date with you, and credits you in the advisory unless you ask not to be named.
