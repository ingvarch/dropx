Usage Examples

Explore different ways to use DropX from your terminal

Quick Start
Basic upload and download examples
Upload a file
COMMAND
curl -T myfile.txt {{HOSTNAME}}
Upload with custom filename
COMMAND
curl -T myfile.txt {{HOSTNAME}}/custom-name.txt
Download a file
COMMAND
curl {{HOSTNAME}}/abc123 -o myfile.txt
Get file information
COMMAND
curl {{HOSTNAME}}/abc123/info
Advanced Features
Max downloads, deletion, and content disposition control
One-time download link
Unavailable after the first download, deleted within an hour
COMMAND
curl -T secret.pdf -H "Max-Downloads: 1" {{HOSTNAME}}
Limited downloads (team sharing)
Unavailable after 5 downloads
COMMAND
curl -T presentation.pdf -H "Max-Downloads: 5" {{HOSTNAME}}
Expire in 24 hours
Unavailable after 24 hours, deleted within an hour
COMMAND
curl -T temp.txt -H "Max-Age-Days: 1" {{HOSTNAME}}
Combined limits
Unavailable after 1 day or 5 downloads
COMMAND
curl -T secret.pdf -H "Max-Age-Days: 1" -H "Max-Downloads: 5" {{HOSTNAME}}
Manual file deletion
Ask for JSON, extract the delete URL and delete the file
COMMAND
# Ask for JSON and extract the delete URL
DELETE_URL=$(curl -H "Accept: application/json" -T myfile.txt {{HOSTNAME}} | jq -r '.delete_url')

# Delete file using the URL
curl -X DELETE "$DELETE_URL"

# Or delete directly: {{HOSTNAME}}/<file_id>/<delete_token>
curl -X DELETE {{HOSTNAME}}/abc123/token123
Force download vs inline display
Control how files are displayed in browser
COMMAND
# Auto-detect (inline for PDFs/images)
{{HOSTNAME}}/abc123

# Force download
{{HOSTNAME}}/get/abc123

# Force inline display
{{HOSTNAME}}/inline/abc123
Security & Encryption
Client-side encryption with GPG and age
GPG encryption
Encrypt files before upload, decrypt after download
COMMAND
# Encrypt and upload
gpg --armor --symmetric --output - myfile.txt | curl -T - {{HOSTNAME}}/myfile.txt.asc

# Download and decrypt
curl {{HOSTNAME}}/abc123 | gpg -d > myfile.txt
age encryption
Also checks that the file was not changed. Install age first: brew install age or apt install age
COMMAND
# Encrypt and upload
age -p myfile.txt | curl -T - {{HOSTNAME}}/myfile.txt.age

# Download and decrypt
curl {{HOSTNAME}}/abc123 | age -d > myfile.txt
Files over {{MAX_BUFFERED_UPLOAD_SIZE}} MB
An upload from a pipe has no Content-Length, so it is limited to {{MAX_BUFFERED_UPLOAD_SIZE}} MB. For a bigger file, which needs an API key, encrypt to a file first, then upload the file
COMMAND
# Encrypt to a file, then upload it
gpg --symmetric --output myfile.txt.gpg myfile.txt
curl -T myfile.txt.gpg -H "X-API-Key: tfr_xxxxx" {{HOSTNAME}}/

Why Client-Side Encryption?

  • Files are encrypted before leaving your device
  • Server never sees your unencrypted data
  • Only you and recipients with the password can decrypt
  • Perfect for sensitive documents and secrets
Shell Functions
Convenient wrapper functions for Bash/Zsh/Fish
Bash/Zsh function
Add to ~/.bashrc or ~/.zshrc
COMMAND
dropx() {
local accept=()
case "$1" in -j|--json) accept=(-H "Accept: application/json"); shift ;; esac
curl "${accept[@]}" -T "$1" {{HOSTNAME}}/"${2:-$(basename "$1")}"
}
Usage:
dropx myfile.txt - uploads as myfile.txt and prints the download link
dropx myfile.txt custom-name.txt - uploads as custom-name.txt
dropx -j myfile.txt - prints the full JSON
Fish shell function
Create file ~/.config/fish/functions/dropx.fish
COMMAND
function dropx
argparse j/json -- $argv; or return
set accept
set -q _flag_json; and set accept -H "Accept: application/json"
set filename (test -n "$argv[2]"; and echo $argv[2]; or basename $argv[1])
curl $accept -T $argv[1] {{HOSTNAME}}/$filename
end
Usage:
dropx myfile.txt - uploads as myfile.txt and prints the download link
dropx myfile.txt custom-name.txt - uploads as custom-name.txt
dropx -j myfile.txt - prints the full JSON

Response Format

An upload prints the download link as plain text. Send -H "Accept: application/json" to get JSON with the details.

TEXT RESPONSE (default)
{{HOSTNAME}}/abc123
JSON RESPONSE (Accept: application/json)
{
"id": "abc123",
"url": "{{HOSTNAME}}/abc123",
"delete_url": "{{HOSTNAME}}/abc123/token123",
"filename": "myfile.txt",
"size": 1024,
"mime_type": "text/plain",
"expires_in": "7d",
"expires_at": 1704067200
}

The delete link is in the X-Url-Delete response header, in both formats.
