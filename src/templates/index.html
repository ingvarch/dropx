DropX

Easy command-line file sharing

Quick Start

Upload a file from your terminal:

# Upload a file
curl -T myfile.txt {{HOSTNAME}}

Or with a specific filename:

curl -T myfile.txt {{HOSTNAME}}/custom-name.txt

With an API key for higher limits:

curl -H "X-API-Key: your-api-key" -T myfile.txt {{HOSTNAME}}

Features

Terminal First

Designed for developers. Upload and share files directly from your command line.

Simple URLs

Get short, memorable URLs for easy sharing. No complicated interfaces.

Rate Limited

Fair usage policies ensure service availability for everyone.

Auto Expiry

Files are automatically cleaned up after the retention period.

API Tiers

Anonymous

  • 10 uploads per hour
  • 50 uploads per day
  • Basic file size limit
  • Standard retention

Standard

  • 100 uploads per hour
  • 500 uploads per day
  • Standard file size limit
  • Standard retention period

Premium

  • 1000 uploads per hour
  • 5000 uploads per day
  • Premium file size limit
  • Extended retention period

More Examples

Download a file:

curl {{HOSTNAME}}/abc123 -o myfile.txt

Get file information:

curl {{HOSTNAME}}/abc123/info

Upload with progress bar:

curl -T myfile.txt {{HOSTNAME}} --progress-bar

Pipe output directly:

echo "Hello World" | curl -T - {{HOSTNAME}}/hello.txt

Response Format

Successful uploads return JSON with download information:

{
"file_id": "abc123",
"url": "{{HOSTNAME}}/abc123",
"filename": "myfile.txt",
"size": 1024,
"mime_type": "text/plain",
"expires_at": "2024-01-01T00:00:00Z"
}
